DAYBOOK LOGO KIT

Included:
- PNG/logo-original-transparent-1024.png: original logo, transparent background.
- PNG/logo-white-monochrome-1024.png: white monochrome silhouette.
- PNG/logo-black-monochrome-1024.png: black monochrome silhouette.
- PNG/logo-sage-monochrome-1024.png: sage monochrome silhouette.
- Icons/: square PNG app/icon exports in common sizes (16–1024 px).
- SVG/logo-original-embedded-raster.svg: SVG wrapper containing the original PNG artwork.

Note:
The original logo artwork includes texture and shading. The SVG file embeds the PNG
to preserve its appearance; it is not a fully editable vector path file.
The monochrome files recolor the complete visible silhouette, including internal
details, and are best used as simple single-color marks.
